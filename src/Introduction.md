# What is Croma++?
Chroma++ is a 3 byte bytecode esolang. Now if this means nothing to you (It certainly meant jack to us the first time I saw that jargon barf X3), that just means that it groups commands into three numbers up to 255 (or smth, idfk). It works by using the RGB values of a pixel in an image to point to code snippets in the library. The R channel is the operation, the G channel is the amount of input values, and the B channel is the output.

# Why Use Chroma++?
Chroma++ not only allows for the execution of code from an external source, but also allows the loading of new programs and updating old ones at runtime due to the way it works! On top of this, it can reduce the file size of programs drastically, whilst retaining all of the data, meaning you can have twice as many programs with half the storage space
