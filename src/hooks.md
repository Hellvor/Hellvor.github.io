# What are Hooks?
A hook is the name used in Chroma++ for the RGB values of a Function Pixel. Specifically, there are three kinds of hooks:
- RedHooks
- GreenHooks
- Bluehooks

# RedHooks
A RedHook, being the Red colour channel, tells the interpreter *what we're actually doing*, quite literally putting the "Function" in Function Pixels. This is the first thing the interpreter looks at when running a Chroma++ program
